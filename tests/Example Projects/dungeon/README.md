# How To Deploy To Android
1. Enable "developer mode" and "usb debugging" in your android phone.
2. deploy the "ArcadeMaker.Engines.MonoGame.Platforms.Android" project to your phone. Do it on RELEASE mode! (debug mode causes serious lags in android, at least on my redmi note 9). You must use the "run without debugging" button to deploy.
3. after you successfuly deployed the android project once, run the IDE, load the dungeon.ampb project file, select your android phone in the "devices" list box in the top menu and click "Run".
